# Environmental Data Visualization Application

A data visualization application built to analyze regional natural hazards and climate risks in Nouvelle-Aquitaine.
The tool imports open-source public datasets covering weather records, air quality measurements, and natural disasters.
It generates custom statistical charts, trend curves, and geographic maps to cross-reference hazards and highlight environmental trends.
The software includes an interactive GUI, automated data cleaning pipelines, and Python test scripts to export chart figures as PNG files.
